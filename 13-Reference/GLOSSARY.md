# Glossary

**API:** Interface between frontend and backend.  
**Auth/JWT:** Login system and signed user access token.  
**Chunk:** Text passage cut from a PDF and indexed with metadata.  
**Citation:** Reference to a trusted retrieved document passage and PDF page.  
**Embedding:** Numeric vector representing text for similarity search.  
**Edge Function:** Server code executed on a hosted runtime.  
**Idempotency:** Repeated request/event causes no extra side effect.  
**MVP:** Smallest usable production-minded version.  
**pgvector:** PostgreSQL extension for vector similarity search.  
**RAG:** Retrieval-augmented generation using relevant source passages.  
**RLS:** PostgreSQL policy enforcing data row permissions.  
**Signed URL:** Temporary authorized upload/download access to private Storage.  
**Webhook:** Server-to-server callback that must be cryptographically verified.  
**Tenant:** Customer account/organization boundary. MVP is per-user tenancy.
